# Product features

These articles define the public product contract for Wording Lens. They are
organized by the behavior a person can use, not by internal package ownership.
Each feature will be implemented in the desktop application and documented in
the offline documentation browser as the implementation lanes land.

- [Status and notifications](status-updates-and-notifications.md)

## Foundation status

The foundation baseline contains no runnable product implementation. The
articles define the behavior to be built, while [INVENTORY.md](../../../INVENTORY.md)
records the current pending status and the evidence required for promotion.
