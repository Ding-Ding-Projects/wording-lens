# Documentation

This documentation describes the intended public behavior of Wording Lens, a
local-first Windows operations cockpit. The foundation release does not yet
ship the application runtime. Statements about future behavior are marked as
planned, and the feature inventory remains the source of truth for evidence.

## Categories

- [Product](features/product/README.md): behavior, settings, operations,
  privacy, and failure handling.
- [Accessibility](features/accessibility/README.md): keyboard, screen reader,
  contrast, motion, focus, and responsive behavior.
- [Release](features/release/README.md): builds, packages, evidence, releases,
  and documentation delivery.

## Reading the status

Every article separates behavior from implementation status. A planned flow is
not a claim that the foundation build provides it. See the [hand-written
feature inventory](../INVENTORY.md) for the complete list of required rows and
the evidence each row needs before it can be marked complete.
