# Inventory index

The inventory set is hand-written and fail-closed. A feature is complete only
when its implementation, localized copy, persistence, documentation, focused
test, built interaction, and real capture are all linked and verified.

- [Canonical feature and per-surface inventory](../INVENTORY.md)
- [Public surface checklist](public-surfaces.md)

The foundation baseline intentionally records pending implementation and
pending evidence. Discovery-only lists are not accepted because a missing
feature would disappear from the check.
